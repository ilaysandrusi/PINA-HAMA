# תוכן האתר — מקור האמת

כל טקסט עסקי, מחיר, שעה ומספר טלפון חיים **כאן**, לא בתוך קומפוננטות.

| קובץ | מה יש בו |
| --- | --- |
| `business.json` | שם, כתובת, טלפונים, שעות, ניווט |
| `menu.json` | תפריט ומחירים |
| `copy.json` | כותרות ופסקאות שיווקיות |

## כללים לסוכנים

1. שינוי מחיר / שעה / טלפון = עריכה ב-JSON, לא ב-JSX.
2. אם שדה מסומן `needsConfirmation: true` — לא להציג אותו כעובדה סופית, ולא למחוק את הדגל בלי אישור בעלים.
3. לא להמציא תפריט, כשרות, רשתות חברתיות או שעות מגוגל.
4. תמונות אמיתיות נכנסות ל-`public/photos/`. עד אז אין סטוק גנרי של מאפים.

## מה דורש אישור בעלים

- שעות פעילות (`hoursNeedsConfirmation`)
- מחירי התפריט (`menu.needsConfirmation`)
- כשרות מדויקת (`kashrut.needsConfirmation`)
- קישור אינסטגרם
- תמונות אמיתיות של המקום והמאפים
