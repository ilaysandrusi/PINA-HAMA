# הפינה החמה

אתר חדש למאפייה **הפינה החמה** בקק״ל 2, באר שבע.

האתר הישן ב-Wix היה שבור (ווידג'טים שלא נטענים, חנות שלא עובדת, תפריט קשה לקריאה). כאן יש בסיס מסודר: תוכן ב-JSON, עברית RTL, ועיצוב חם שמתאים למקום.

## הרצה מקומית

```bash
npm install
npm run dev
```

ואז לפתוח http://localhost:3000

## מה כבר בנוי

- בית, תפריט, קצת עלינו, הגעה
- שעות, טלפון, וואטסאפ ומפה
- תפריט שהועתק מהאתר הישן
- כללי עבודה לסוכנים ב-`AGENTS.md`

## איפה משנים תוכן

לא בקומפוננטות. כאן:

- `content/business.json` — כתובת, טלפונים, שעות
- `content/menu.json` — מנות ומחירים
- `content/copy.json` — כותרות וטקסטים

## לפני השקה צריך מהעסק

1. אישור שעות פעילות
2. אישור מחירי תפריט
3. תמונות אמיתיות ל-`public/photos/`
4. אישור כשרות (בלי שם בד״ץ עד אז)
5. קישור לאינסטגרם אם יש
6. דומיין
